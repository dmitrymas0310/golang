# Сервисы Gateway и Ledger

Репозиторий содержит два независимых Go-сервиса:

- `hw_2/gateway` — HTTP-сервис Gateway;
- `hw_2/ledger` — сервис Ledger с бюджетами и транзакциями в памяти.

## Требования

- установлен Go версии, указанной в файлах `go.mod`;
- команды выполняются из корня репозитория.

Проверить установленную версию Go:

```bash
go version
```

## Запуск Gateway

Перейдите в каталог сервиса и запустите его:

```bash
cd hw_2/gateway
go run .
```

Gateway будет доступен по адресу `http://localhost:8080`.

Для проверки в другом терминале выполните:

```bash
curl http://localhost:8080/ping
```

Ожидаемый ответ:

```text
pong
```

Остановить сервис можно сочетанием клавиш `Ctrl+C`.

## Запуск Ledger

Из корня репозитория перейдите в каталог Ledger и запустите весь Go-пакет:

```bash
cd hw_2/ledger
go run .
```

Важно использовать `go run .`, а не `go run main.go`, поскольку структуры и функции Ledger находятся в нескольких файлах.

При запуске Ledger:

1. открывает файл `budgets.json`;
2. загружает из него бюджеты в память;
3. добавляет тестовые транзакции;
4. отклоняет транзакции, превышающие бюджет категории;
5. выводит загруженные бюджеты, ошибки и сохранённые транзакции в консоль.

Ledger нужно запускать именно из каталога `hw_2/ledger`, поскольку относительный путь `budgets.json` вычисляется от текущего рабочего каталога.

Все бюджеты и транзакции хранятся в оперативной памяти и удаляются после завершения программы.

## Файл бюджетов

Начальные бюджеты задаются в `hw_2/ledger/budgets.json` в виде массива JSON-объектов:

```json
[
  {
    "Category": "Food",
    "Limit": 2000,
    "Period": "2026-10"
  },
  {
    "Category": "Transport",
    "Limit": 500,
    "Period": "2026-10"
  }
]
```

Поля бюджета:

- `Category` — категория расходов;
- `Limit` — максимальная сумма транзакций категории;
- `Period` — период действия бюджета.

При отсутствии файла или некорректном JSON Ledger выводит сообщение об ошибке и завершает работу. Если сумма сохранённых транзакций категории вместе с новой транзакцией превышает `Limit`, новая транзакция не сохраняется.

## Проверка сборки

Каждый сервис является отдельным Go-модулем, поэтому проверять их нужно отдельно:

```bash
cd hw_2/gateway
go test ./...
```

```bash
cd hw_2/ledger
go test ./...
```

Сообщение `[no test files]` означает, что автоматических тестов пока нет, но пакет успешно скомпилирован.
